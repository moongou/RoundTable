# Immersive Round Table UI Design

RoundTable 圆桌思辨讨论平台的沉浸式 UI 重新设计，采用暖色书房风 + Canvas 场景绘制方案。

## 设计目标

- 逼真的木质圆桌场景，温暖书房氛围
- 全站沉浸式体验（首页 + 讨论房间 + 设置页）
- 丰富的动画和视觉反馈
- 目标用户：中国小学生

## 视觉风格

- **风格**：沉浸式圆桌场景
- **氛围**：暖色书房风 — 传统书房/图书馆的圆桌讨论，温暖灯光，智慧与温暖并存
- **实现**：Canvas CustomPainter 绘制场景 + Flutter Widget 处理交互

## 第一节：首页 — "推开书房的门"

### 场景描述

用户打开应用，看到一间温暖的书房。画面中心是一张木质圆桌，桌面上散落着卷轴（话题卡片）。桌旁预坐着 3-4 个 AI 角色（半透明/等待状态），像在等你入座。

### 布局

- **背景**：深色木纹书架/墙壁，微弱的暖光从上方洒下
- **中央区域**：木质圆桌俯视图，桌面纹理用 Canvas 绘制（径向渐变模拟木纹）
- **卷轴卡片**：3-4 张卷轴散落在桌面上，微倾斜摆放，标题用毛笔字风格，hover/选中时卷轴展开
- **角色区域**：桌旁围坐着 AI 角色，半透明灰度显示（未选中状态），选中后变为彩色并发光
- **底部入口**：一把空椅子（你的位置），点击后输入名字，卷轴和角色都选好后椅子点亮，出现"入座开始"按钮
- **右上角**：设置齿轮图标，点击进入设置页

### 动画

- 入场：镜头从上缓缓拉近（缩放动画），像推开书房门走近圆桌
- 卷轴 hover：微微展开 + 发出金色柔光
- 角色选中：从灰度渐变为彩色 + 轻微弹跳
- 入座按钮：呼吸发光效果

## 第二节：讨论房间 — "围坐圆桌，各抒己见"

### 场景描述

入座后进入讨论房间，你"坐在"圆桌旁。圆桌俯视/微倾斜视角，你和 AI 角色围坐一圈。当前发言者位置发光，消息以气泡形式出现在发言者身旁。

### 布局

- **背景**：与首页一致的书房环境，光线更集中到桌面中央（聚光灯效果）
- **中央圆桌**：木质桌面，Canvas 绘制木纹 + 径向光晕，桌面有当前话题卷轴（半展开）
- **参与者围坐**：圆形排列，主持人固定在 12 点钟位置。每人有 emoji 头像 + 名牌 + 角色色光环
- **发言气泡**：从发言者位置向外弹出，带角色色边框，2-3 秒后缩小淡出到消息历史
- **桌面消息**：当前正在说的话以大字显示在桌面中央
- **底部控制栏**：半透明毛玻璃条，包含文本输入框 / PTT 按钮 / 打断按钮

### 发言状态视觉

- **发言中**：头像外圈发光脉冲 + 名牌高亮 + 桌面中央文字
- **思考中**：头像上方出现"..."省略号气泡，微微浮动
- **等待发言（你）**：椅子位置发出蓝色邀请光圈，"轮到你发言了"文字浮现
- **举手打断**：头像旁出现举手图标 + 抖动动画

### 消息历史

- 右侧抽屉，从右向左拉出查看完整记录
- 羊皮纸底色 + 角色色条

### 动画

- 发言切换：光圈平滑过渡
- 消息出现：气泡从发言者弹出 + fadeIn
- 讨论结束：灯光渐暗，圆桌上出现"讨论已结束"卷轴

## 第三节：Canvas 绘制架构

### Painters

- **BookshelfPainter** — 书房背景（书架纹理 + 顶部光源）
- **RoundTablePainter** — 圆桌桌面（木纹径向渐变 + 边缘高光 + 阴影）
- **CandlelightPainter** — 烛光粒子效果（浮动光点）
- **ScrollCardPainter** — 卷轴卡片（纸卷 + 微卷边 + 金线框）

### Widgets（布局+交互）

- **ImmersiveHomeScreen** — 首页整体布局
- **ImmersiveSessionScreen** — 讨论房间整体布局
- **TableParticipantRing** — 围坐排列容器
- **SpeakingBubble** — 发言气泡
- **GlowAvatar** — 发光头像（复用+增强 ParticipantAvatar）
- **ScrollTopicCard** — 卷轴话题卡片
- **GlassControlBar** — 底部毛玻璃控制栏

### 文件变更范围

## 第四节：交互细节与状态流转

### 首页交互流程

```
加载中 → 书房场景淡入 → 卷轴/角色依次入场（弹性动画）
→ 点击卷轴展开话题详情 → 选中高亮
→ 点击角色头像 → 灰度→彩色切换
→ 输入名字 → 空椅子亮起
→ 点击"入座开始" → 镜头拉近动画 → 过渡到讨论房间
```

### 讨论房间状态流转

```
入座动画 → 等待主持人开场 → 主持人发言(桌面中央文字+气泡)
→ AI角色轮流发言 → 轮到你(蓝色光圈+提示音)
→ 输入/语音发言 → 提交后光圈移走 → 继续轮转
→ 举手打断 → 举手动画 → 主持人回应
→ 讨论结束 → 灯光渐暗 → 结束卷轴 → 返回首页
```

### 加载与错误状态

- **首次加载**：书房场景先显示轮廓，Canvas 绘制完成后淡入完整画面（< 500ms）
- **网络断开**：烛光粒子变红 + 顶部半透明警告条"连接中断，正在重连..."
- **WebSocket 重连中**：画面变暗，蜡烛闪烁加快
- **API 调用失败**：卷轴上出现红色封印效果 + 错误提示
- **无话题数据**：桌面显示空卷轴"暂无话题，请稍后再来"

### 性能考虑

- CustomPainter 使用 `shouldRepaint` 严格判断，只在状态变化时重绘
- 烛光粒子控制在 15-20 个，使用 AnimationController 而非每帧重建
- 未发言参与者不触发重绘
- Canvas 静态部分（桌面、背景）使用 PictureRecorder 缓存

### 设置页

- 功能完全保留现有逻辑
- 样式融入书房风：深棕底 + 暖色卡片 + 手写体分区标题
