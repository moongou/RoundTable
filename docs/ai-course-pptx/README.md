## 🎯 课程目标

面向小学四年级学生，通过大量比喻和实例，讲解人工智能的基本概念、工作原理、应用场景和未来展望。课程结合 RoundTable 项目作为真实案例。

## 📖 课程结构（51页）

1. **封面与导航**（第1-2页）
2. **AI是什么**（第3-6页）- 基本概念、与普通电脑的区别、生活中的AI、历史
3. **AI怎么学习**（第7-11页）- 数据、训练、三种学习方法、神经网络、深度学习
4. **AI的能力**（第12-27页）- NLP、计算机视觉、语音、大语言模型、Agent、Prompt、图像生成、写作、翻译
5. **AI的应用**（第28-32页）- 医疗、交通、教育、游戏、艺术
6. **AI的组成与架构**（第33-41页）- 五感总结、局限性、安全、技术架构、通信、数据、GPU、云计算
7. **AI的现在与未来**（第42-47页）- 发展现状、中国AI、AGI、未来应用、人与AI关系、学习建议
8. **互动与总结**（第48-51页）- 测验、讨论、总结、致谢
